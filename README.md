# 🎮 Furina Jogos

Mini jogos em **HTML, CSS e JavaScript puro**, feitos para rodar como **Telegram Mini App** e também em qualquer navegador.

## Jogos

| | Jogo | Descrição |
|---|---|---|
| ⭕ | **Jogo da Velha** | Contra a máquina (fácil ou difícil) ou com um amigo |
| 🧠 | **Memória** | Ache os 8 pares no menor número de jogadas |
| 🐍 | **Cobrinha** | Coma sem bater nas paredes nem em você mesma |
| 🔢 | **2048** | Some as peças até chegar ao 2048 |
| ✊ | **Pedra, Papel e Tesoura** | Duelo contra a máquina, com placar |
| 🔤 | **Forca** | Adivinhe a palavra por categoria |

## Como jogar

Mande `/jogos` para o bot **Furina De Fontaine** no Telegram, ou abra a página direto no navegador.

## Detalhes

- Um único arquivo (`index.html`), sem dependências e sem etapa de build.
- Segue o tema do Telegram (claro ou escuro) automaticamente.
- Funciona por toque, deslize ou teclado.
- Recordes e placares ficam salvos no próprio aparelho (`localStorage`).

## Publicação

Servido pelo **GitHub Pages**, a partir da branch `main`.
